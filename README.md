# kotlin-omok

## 기능 목록

### 위치
- [x] 위치는 행과 열을 가진다.

### 바둑돌
- [x] 바둑돌은 위치와 색깔을 가진다.

### 바둑판
- [x] 바둑판은 길이와 너비를 가진다.
- [x] 바둑판의 기본 길이와 너비는 15다.
- [x] 바둑판은 바둑돌들을 가진다.
- [x] 바둑판에 돌을 둘 수 있다.
- [x] 바둑판에서 이미 돌이 있는 위치에는 바둑돌을 둘 수 없다.

### 게임
- [x] 게임은 바둑판, 규칙과 마지막 돌을 가진다.
- [x] 게임은 어떤 플레이어의 차례인지 판단할 수 있다.
- [x] 게임은 플레이어가 둔 수의 결과를 판단할 수 있다.

### 규칙
- [x] 규칙은 금수 여부를 판단할 수 있다.
- [x] 규칙은 오목 여부를 판단할 수 있다.

### UI
- [x] 콘솔 및 모바일 앱으로 게임을 할 수 있다.
- [x] 모바일 앱을 재시작하더라도 이전 게임 상태가 복구된다.
