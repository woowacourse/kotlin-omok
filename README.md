# kotlin-omok

## 🛠️ 구현할 기능

- [X] 위치를 입력 받는다.
    - [X] 흑돌부터 입력을 받는다.
    - [X] 위치는 x좌표, y좌표 순서로 입력한다.
- [x] 돌을 오목판(좌표)에 놓을 수 있다.
    - [X] 돌은 흑, 백색을 가질 수 있다.
    - [X] 돌은 좌표를 가질 수 있다.
    - [x] 돌은 같은 좌표를 가질 수 없다.
- [x] 오목판은 좌표를 갖는다.
    - [X] x좌표는 A-O까지이다.
    - [X] y좌표는 1-15까지이다.
- [X] 한 색깔의 돌이 연속으로 5개 이상시 승리한다.


- [X] X는 1 - 15 사이의 점을 가진다.
- [X] Y는 1 - 15 사이의 점을 가진다.
- [ ] 오목판은 정사각형이다.
- [X] 각 점들은 초기에 돌이 놓여져 있지 않다.
- [X] 검은색 돌을 점위에 놓으면 점 위에는 흑돌이 있다.
- [X] 백색 돌을 점위에 놓으면 점 위에는 백돌이 있다.
- [X] 자리에 돌이 있으면, 그 자리에 돌을 놓지 못한다.
- [X] 콘솔 UI에서 게임이 가능해야한다.
- [X] 모바일 앱에서 오목 게임이 가능해야한다.
