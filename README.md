# kotlin-omok

## 오목판
- 오목판은 15x15 
  - [x] 가로 범위 A~O 
  - [x] 세로 범위 1~15
- [x] 바둑돌이 이미 존재하는 위치는 둘 수 없다
- [x] 바둑돌의 위치를 저장한다.

## 판정
- [x] 가로나 세로, 대각선으로 다섯 개의 연속된 돌이 있을 경우 승리한다

## 1차 피드백 사항
- View, Controller, Model 값 생성 위치 분류
- placeStone, canPlace 예외 처리 및 역할 수정
- Board와 Rule의 책임 분리 및 역할 분리
- Column은 도메인에서 처리할 값으로 받아야하니 입력 처리를 View또는 중간 계층으로 처리해서 이전
- 매직 넘버 포장
- 인터페이스를 통해 외부 라이브러리를 모르도록 변경(전략 패턴 활용)
- 상태 패턴 구조 수정
- 단일 책임 원칙 준수
