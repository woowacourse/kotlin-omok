## 오목 게임 기능 요구 사항

### 기본 게임 요구 사항
- [x] **오목돌의 색상**
  - 오목돌은 흑(Black)과 백(White) 색을 가진다.

- [x] **오목돌의 위치**
  - 오목돌은 각 칸에 놓이며, 칸의 상태에 따라 돌을 놓을 수 있다.

- [x] **칸의 상태**
  - 각 칸은 세 가지 상태를 가진다:
    - `BLACK` (흑돌)
    - `WHITE` (백돌)
    - `OPEN` (빈 칸)

- [x] **오목판 크기**
  - 오목판은 15x15 크기의 칸으로 구성된다.

- [x] **돌을 두는 규칙**
  - 각 돌은 위치를 가지고 있으며, 착수된 돌은 오목판에 기록된다.
  - 중복된 위치에 돌을 둘 수 없다.

- [x] **게임 승패 조건**
  - 오목판에서 연속된 5개의 돌이 가로, 세로, 대각선 방향으로 이어지면 승리로 간주된다.
  - 6목 이상의 연속된 돌도 승리 조건에 포함된다.

- [x] **금수 조건 (흑돌에 적용)**
  - `3-3`: 흑돌이 3개의 연속된 돌을 놓을 수 있는 경우, 착수가 금지된다.
  - `4-4`: 흑돌이 4개의 연속된 돌을 놓을 수 있는 경우, 착수가 금지된다.
  - `장목`: 6목 이상의 연속된 돌이 있으면 착수가 금지된다.

- [x] **마지막 돌의 위치**
  - 마지막으로 놓은 돌의 위치를 추적할 수 있다.

<br>

### 3, 4단계 요구 사항

- [x] **모바일 앱 구현**
  - 기존 오목 로직을 Android 프로젝트로 이식한다.
  - 앱 UI를 적용할 때 도메인 객체의 변경을 최소화하여 구현한다.

- [x] **게임 재시작 기능**
  - 모바일 앱을 재시작하더라도 이전에 하던 오목 게임을 이어서 진행할 수 있어야 한다.

- [x] **게임방 기능 (선택)**
  - 오목 게임방을 생성하고, 다른 사용자가 게임방에 입장할 수 있는 기능을 추가한다.

- [ ] **게임 기록 관리 (선택)**
  - 사용자의 오목 게임 기록을 관리할 수 있도록 한다.
