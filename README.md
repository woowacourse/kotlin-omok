# kotlin-omok

## 소개
오목은 두 사람이 번갈아 돌을 놓아 가로나 세로, 대각선으로 다섯 개의 연속된 돌을 먼저 만들면 승리하는 게임이다.
6목 이상의 장목도 착수 가능하며 승리 조건으로 인정한다.

## 기능 명세
오목돌
- [x] row 위치를 가진다.
- [x] col 위치를 가진다.

바둑판
- [ ] 바둑판은 15개의 행과 15개의 열을 가진다.
- [ ] 바둑판은 바둑판을 생성할 수 있다.
- [ ] 바둑판은 null 혹은 바둑돌을 놓을 수 있다. (= 바둑판은 모든 바둑돌의 위치를 알고 있다)
- [ ] 바둑판의 크기를 넘어가면 바둑돌을 놓을 수 없다.

판정
- [ ] 같은 색상의 오목돌이 가로, 세로, 대각선으로 5개면 승리한다.
- [ ] 더 이상 오목돌을 오목판에 둘 수 없으면 무승부가 된다.

턴
- [ ] 턴은 색상을 가진다
- [ ] 턴은 바둑판에게 돌을 두라고 한다.

** 생각할 요소
- [ ] 오목돌과 바둑판 중 하나는 색상을 가질지 결정한다
- [ ] 턴
