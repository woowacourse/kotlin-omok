# kotlin-omok

## 기능 요구사항

- [x] 위치는 행을 가진다.
- [x] 위치는 열을 가진다.
- [x] 줄은 0부터 14까지의 값을 가진다.
- [x] 칸은 위치와 상태를 가진다.
- [x] 칸의 상태는 흑/백/비어있음으로 나뉜다.
- [x] 바둑판에 돌을 둘 수 있다.
- [x] 바둑판에 돌을 두면 마지막 돌이 갱신된다.
- [x] 바둑판은 오목 상태를 판단한다.
- [x] 오목의 상태는 백 오목/흑 오목/진행 중으로 나뉜다.
- [x] 흑/백은 이미 돌이 있는 자리인지 알 수 있다.
- [x] 흑/백은 돌을 둘 수 있다.
- [x] 게임은 마지막 돌을 가진다.
- [x] 플레이어가 수를 두면 마지막 돌이 바뀐다.
- [x] 플레이어가 수를 두면 게임 상태를 알려준다.
