# 🚀 오목
## 기능 요구 사항
오목은 두 사람이 번갈아 돌을 놓아 가로나 세로, 대각선으로 다섯 개의 연속된 돌을 먼저 만들면 승리하는 게임이다.

## 기능 목록
- [ ] 바둑판은 15x15이다.
- [ ] 바둑돌은 흑과 백이다.
- [ ] 흑부터 번갈아 돌을 놓는다.
- [ ] 돌을 입력받은 위치에 놓는다.
- [ ] 마지막 돌의 위치를 저장한다.
- [ ] 가로로 다섯 개의 연속된 돌을 놓으면 승리한다.
- [ ] 세로로 다섯 개의 연속된 돌을 놓으면 승리한다.
- [ ] 대각선으로 다섯 개의 연속된 돌을 놓으면 승리한다.
