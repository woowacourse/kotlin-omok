# kotlin-omok

## 오목
- 위치
  - [x] 가로 위치와 세로 위치를 가진다. 
  - [x] 오목판에서 제외된 위치에 둘 경우 예외를 발생시킨다.
- 돌 
  - 돌은 위치와 타입을 가진다.
- 오목판
  - 돌을 추가한다
- 턴
  - 돌을 둘 수 있는지 확인한다.
  - 돌을 둔다.
- 게임 진행
  - 돌들의 상태를 통해 진행할지 게임을 끝낼지 확인한다.
- 게임 끝
  - 게임이 끝날때 둔 돌을 반환한다.

## 1차 피드백 사항
- [x] View, Controller, Model 값 생성 위치 분류
- placeStone, canPlace 예외 처리 및 역할 수정
- Board와 Rule의 책임 분리 및 역할 분리
- Column은 도메인에서 처리할 값으로 받아야하니 입력 처리를 View또는 중간 계층으로 처리해서 이전
- 매직 넘버 포장
- 인터페이스를 통해 외부 라이브러리를 모르도록 변경(전략 패턴 활용)
- 상태 패턴 구조 수정
- 단일 책임 원칙 준수
