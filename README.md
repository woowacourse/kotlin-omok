# kotlin-omok

## 기능 목록

- OmokGrid
    - [x] 15x15 크기를 가진 보드를 생성한다.
    - [x] 좌표와 돌 상태를 받으면 해당 위치에 돌을 놓는다.
        - [x] 좌표에 이미 돌이 있으면 예외를 던진다.


- omokGame
    - [x] 현재 돌이 오목인지 확인한다.


- 입력
    - [x] 돌을 놓을 위치를 입력 받는다.


- 출력
    - [x] 게임 시작 메시지를 출력한다.
    - [x] 보드의 상태를 출력한다.
