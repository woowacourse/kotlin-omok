# kotlin-omok

## 📚️ 개요

블랙잭 게임을 구현한다.

## 🛠️ 구현할 기능

### 위치

- [x] 같은 행 인지 확인할 수 있다.
- [x] 증가 대각선 인지 확인할 수 있다.
- [x] 감소 대각선 인지 확인할 수 있다.

### 행

- [x] 유효한 행이 아니라면 예외를 반환한다.
- [x] 같은 행 인지 확인할 수 있다.

### 열

- [x] 유효한 열이 아니라면 예외를 반환한다.
- [x] 같은 열 인지 확인할 수 있다.

### 오목돌

- [x] 위치, 색깔을 가지고 있다.

### 오목판

- [x] 판에 돌을 추가할 수 있다.
- [x] 돌이 5개가 이어졌는지

### rule 객체

- [x] 각 방향으로 옆에 몇개의 돌이 있는지 파악한다
- [x] 양 방향의 돌 갯수를 합산하여 5개 이상인지 판단한다

### 입력

- [x] 돌을 놓을 좌표를 입력받는다

### 출력

- [x] 매 턴 마다 돌들의 위치를 출력한다
- [x] 누구의 승리인지 출력한다
## 🛠️ (2단계) 구현할 기능

- [x] 닉네임을 저장할 수 있다
- [x] 방을 생성할 수 있다
- [x] 방에 게임 기록을 저장할 수 있다
- [x] 게임 기록을 불러올 수 있다
