# kotlin-omok

## 📚️ 개요

블랙잭 게임을 구현한다.

## 🛠️ 구현할 기능

### 위치
- [x] 같은 행 인지 확인할 수 있다. 
- [ ] 증가 대각선 인지 확인할 수 있다.
- [ ] 감소 대각선 인지 확인할 수 있다.

### 행

- [x] 유효한 행이 아니라면 예외를 반환한다.
- [x] 같은 행 인지 확인할 수 있다.

### 열

- [x] 유효한 열이 아니라면 예외를 반환한다.
- [x] 같은 열 인지 확인할 수 있다.

### 오목돌

- [ ] 위치, 색깔을 가지고 있다.

### 오목판

- [ ] 돌이 5개가 이어졌는지

### validation 객체 (놓을 수 있는지)

- [ ] 다른 돌이 이미 선점 한 위치인지

### 입력

- [ ] 돌을 놓을 좌표를 입력받는다

### 출력

- [ ] 매 턴 마다 돌들의 위치를 출력한다
- [ ] 누구의 승리인지 출력한다
