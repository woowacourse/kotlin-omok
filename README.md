# 🐶 kotlin-omok

## 📚️ 개요

오목 게임을 구현한다.

## 🛠️ 구현할 기능

- [x] 오목판은 15 x 15 사이즈이다.
- [x] 각 행은 숫자이고, 각 열은 알파벳이다.
- [x] 각 칸마다 돌을 둘 수 있다.
- [x] 각 칸마다 위치 정보를 가지고 있다.
- [x] 각 칸마다 현재 상태를 가지고 있다.
- [x] 플레이어가 돌을 두면 턴을 넘긴다.
- [x] 이미 돌을 둔 자리에는 돌을 둘 수 없다.
- [x] 연속된 5개 이상의 돌을 둔 플레이어가 승리한다.
- [x] 오목판을 다 채우면 무승부다.
